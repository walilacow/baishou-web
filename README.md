# 百獸真經（網頁版・測試版）

武俠卡牌對戰《百獸真經》的網頁版，小盜工作室（EngieStudio）出品。**這是測試中的版本，規則與數值可能隨時調整，進度可能不保留。**

- 一般對戰：選門派基本牌組，可以自己換牌，對上電腦。
- 自己組牌：從七派基本牌組出發，牌庫是全部的卡，任意增減（張數、同名上限、本門主角等限制由遊戲引擎檢查）；組好的牌組存在瀏覽器（localStorage）。
- 規則頁：`rules.html`（建置時由遊戲規則文件自動產生）。

## 怎麼運作

遊戲引擎是同一份 Swift 程式（與 iOS／Mac 版共用），用 SwiftWasm 編成 WebAssembly 在瀏覽器裡執行；前端是純 JavaScript，沒有伺服器、不需要登入、不收集任何資料。

這個 repo 只放建置後的網頁（HTML／JS／wasm／圖片／資料），不含遊戲引擎原始碼。

## 版本與來源

- 網頁版版號：測試版 0.1.7（Build 7）。
- 對局設定（內容包、相剋、剛上場保護等）與 iOS／Mac 試玩版共用同一份核心程式（CardGameCore 的 TrialConfig），規則只有一份。網頁版沒有劇情模式。
- 規則頁由規則文件在建置時自動產生。
